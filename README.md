# RETIRED — prim.obif

**Successor: [prim.brand](https://github.com/eidos-agi/prim.brand).**

OBIF (Open Brand and Identity Format) is retired. The brand prim is its own profile: `profile: brand`. Not an OKF add-on. The kit includes identity, tokens, logos, fonts, and running blocks.

Do not add features here. Old packs with `profile: obif` are read as brand kits without implementations.

House kit: [`prim.brand/packs/eidos`](https://github.com/eidos-agi/prim.brand/tree/main/packs/eidos).
